# 🚀 Meta Automation v1.0.0 - Tự động hóa Meta.ai AI [![English](https://img.shields.io/badge/English-blue)](README.md) [![中文](https://img.shields.io/badge/中文-red)](README_zh.md)

**Meta Automation** là công cụ năng suất tự động hóa quy trình sáng tạo của bạn trên Meta.ai. Dừng việc nhập từng prompt thủ công—tự động hóa quy trình và tạo video, ảnh ở quy mô lớn.

-----

## ✨ Các tính năng chính

* **🚀 Xử lý hàng loạt:** Xếp hàng hàng chục hoặc hàng trăm prompt và để tiện ích tự động gửi và tạo nội dung.
* **🎬 Tự động Văn bản thành Video:** Tạo video từ mô tả văn bản. Hỗ trợ xử lý hàng loạt với thời gian chờ tùy chỉnh.
* **🎬 Ảnh thành Video:** Dùng ảnh nguồn và prompt để tạo video động.
* **🖼️ Tạo hàng loạt Văn bản thành Ảnh:** Tạo nhiều ảnh với tỷ lệ khung hình 16:9, 9:16, 1:1.
* **🖼️ Ảnh thành Ảnh:** Tạo biến thể ảnh từ ảnh nguồn và prompt.
* **⚙️ Điều khiển chuyên nghiệp:**
    * **Prompt đồng thời:** Xử lý nhiều prompt cùng lúc để tiết kiệm thời gian.
    * **Chờ thông minh (Smart Delays):** Thiết lập khoảng thời gian giữa các prompt để quản lý giới hạn tốc độ.
    * **Tự động tải xuống:** Tự động tải kết quả khi tạo xong.
* **📊 Giám sát hàng đợi thời gian thực:** Theo dõi tiến trình với thanh trạng thái và danh sách prompt trong Side Panel.
* **📂 Quản lý tệp:** Tải xuống được sắp xếp vào thư mục theo dự án.
* **🌐 Đa ngôn ngữ:** Tiếng Anh, Tiếng Việt, Tiếng Trung, Tiếng Hàn, Tiếng Nhật, Tiếng Tây Ban Nha.

## 📥 Cài đặt

## 📖 Hướng dẫn sử dụng

### Bắt đầu

1. **Truy cập Meta.ai**
   - Mở [meta.ai/media](https://www.meta.ai/media) hoặc [meta.ai](https://meta.ai)
   - Tiện ích hoạt động trên trang Media của Meta.ai.

2. **Mở tiện ích**
   - Nhấn biểu tượng tiện ích trên thanh công cụ Chrome. Ghim để truy cập nhanh!

3. **Cấu hình hàng loạt**
   - Trong tab **Điều khiển**, thiết lập:
     - **Prompt đồng thời:** Số prompt chạy cùng lúc.
     - **Thời gian chờ prompt:** Thời gian nghỉ giữa mỗi lần gửi prompt.

4. **Chọn chế độ**
   - Chọn: **Văn bản thành Video**, **Ảnh thành Video**, **Văn bản thành Ảnh**, hoặc **Ảnh thành Ảnh**.

### 1. Chế độ Văn bản thành Video

1. Chọn chế độ **Văn bản thành Video**.
2. Nhập prompt vào ô (tách mỗi prompt bằng **dòng trống**).
3. Hoặc nhấn biểu tượng **Tải lên** để nhập danh sách prompt từ file `.txt`.
4. Nhấn **Chạy** để bắt đầu.

**Ví dụ Prompt:**
```
Một thành phố cyberpunk tương lai với ánh đèn neon phản chiếu trong mưa.
Camera lướt qua các con hẻm hẹp.

Một khu vườn Nhật Bản yên bình với hoa anh đào rơi xuống ao.
Camera zoom chậm vào những con cá koi đang bơi bên dưới.
```

### 2. Chế độ Ảnh thành Video

1. Chọn chế độ **Ảnh thành Video**.
2. Nhấn tải lên hoặc kéo & thả ảnh nguồn.
3. Nhập prompt (tách bằng dòng trống). Ảnh sẽ được dùng với mỗi prompt.
4. Nhấn **Chạy**.

### 3. Chế độ Văn bản thành Ảnh

1. Chọn chế độ **Văn bản thành Ảnh**.
2. Nhập mô tả chi tiết cho ảnh.
3. Cấu hình **Tỷ lệ khung hình** trong tab Cài đặt.
4. Nhấn **Chạy**.

### 4. Chế độ Ảnh thành Ảnh

1. Chọn chế độ **Ảnh thành Ảnh**.
2. Tải lên ảnh nguồn.
3. Nhập prompt cho các biến thể ảnh.
4. Nhấn **Chạy**.

## ⚙️ Cấu hình Cài đặt

Truy cập tab **Cài đặt** để tùy chỉnh:

* **Chế độ mặc định:** Chế độ mở mặc định.
* **Tỷ lệ khung hình mặc định:** 16:9, 9:16 hoặc 1:1.
* **Số đầu ra mỗi prompt:** Số video hoặc ảnh tạo cho mỗi prompt.
* **Tự động tải xuống:** Bật tải kết quả khi tạo xong.
* **Ngôn ngữ:** English, Tiếng Việt, 中文, 한국어, 日本語, Español.

## 💡 Mẹo & Thực hành tốt nhất

1. **Thời gian chờ:** Gặp giới hạn tốc độ thì tăng **Thời gian chờ prompt** trong tab Điều khiển.
2. **Chạy đồng thời:** Bắt đầu với 1 prompt đồng thời rồi tăng dần theo tài khoản.
3. **Viết Prompt:** Viết cụ thể. Prompt chi tiết cho kết quả tốt hơn. Tách nhiều prompt bằng dòng trống.
4. **Quản lý tệp:** Tải xuống tự động sắp xếp theo thư mục dự án.
