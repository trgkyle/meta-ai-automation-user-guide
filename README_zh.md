# 🚀 Meta 自动化 v1.0.0 - Meta.ai AI 自动化 [![English](https://img.shields.io/badge/English-blue)](README.md) [![Tiếng Việt](https://img.shields.io/badge/Tiếng%20Việt-green)](README_vi.md)

**Meta 自动化** 是一款生产力工具，用于在 Meta.ai 上自动化您的创作流程。告别手动逐个输入提示词——实现流程自动化，大规模生成视频和图片。

-----

## ✨ 主要功能

* **🚀 批处理：** 排队数十或数百个提示词，让扩展程序自动提交和生成。
* **🎬 文本转视频自动化：** 从文本描述生成视频。支持带自定义延迟的批处理。
* **🎬 图片转视频：** 使用源图片和提示词创建动态视频。
* **🖼️ 文本转图片批处理：** 创建多张图片，支持宽高比 16:9、9:16、1:1。
* **🖼️ 图片转图片：** 从源图片和提示词生成图片变体。
* **⚙️ 专业控制：**
    * **并发 Prompt：** 同时处理多个提示词以节省时间。
    * **智能延迟：** 设置提示词之间的间隔以管理速率限制。
    * **自动下载：** 生成完成后自动下载结果。
* **📊 实时队列监控：** 通过侧边面板中的状态栏和活跃提示词列表监控进度。
* **📂 有序文件管理：** 下载内容按项目分类到文件夹。
* **🌐 多语言支持：** 英语、越南语、中文、韩语、日语、西班牙语。

## 📖 使用指南

### 开始使用

1. **访问 Meta.ai**
   - 打开 [meta.ai/media](https://www.meta.ai/media) 或 [meta.ai](https://meta.ai)
   - 扩展程序在 Meta.ai Media 页面上运行。

2. **打开扩展程序**
   - 点击 Chrome 工具栏中的扩展程序图标。建议固定以便访问！

3. **配置批量设置**
   - 在 **控制** 标签页中可设置：
     - **并发 Prompt：** 同时运行的提示词数量。
     - **提示间隔：** 每次提交提示词之间的等待时间。

4. **选择模式**
   - 可选：**文本转视频**、**图片转视频**、**文本转图片** 或 **图片转图片**。

### 1. 文本转视频模式

1. 选择 **文本转视频** 模式。
2. 在输入框中输入提示词（每个提示词之间用 **空行** 分隔）。
3. 或点击 **上传** 图标从 `.txt` 文件导入提示词列表。
4. 点击 **运行** 开始批处理。

**示例提示词：**
```
一个充满霓虹灯的未来派赛博朋克城市，雨水倒映着灯光。
摄像机穿过狭窄的小巷。

一个宁静的日本花园，樱花飘落进池塘。
摄像机缓慢放大观察下方游动的锦鲤。
```

### 2. 图片转视频模式

1. 选择 **图片转视频** 模式。
2. 点击上传或拖放源图片。
3. 输入提示词（用空行分隔）。图片将与每个提示词一起处理。
4. 点击 **运行**。

### 3. 文本转图片模式

1. 选择 **文本转图片** 模式。
2. 为图片输入详细描述。
3. 在设置标签页中配置所需的 **宽高比**。
4. 点击 **运行**。

### 4. 图片转图片模式

1. 选择 **图片转图片** 模式。
2. 上传源图片。
3. 输入图片变体的提示词。
4. 点击 **运行**。

## ⚙️ 设置配置

访问 **设置** 标签页自定义体验：

* **默认模式：** 设置默认开启的模式。
* **默认宽高比：** 可选 16:9、9:16 或 1:1。
* **每个提示词的输出数量：** 设置每个提示词生成的视频或图片数量。
* **自动下载：** 生成完成后自动下载。
* **语言：** 在 English、Tiếng Việt、中文、한국어、日本語、Español 之间切换。

---

## 💡 提示与最佳实践

1. **等待时间：** 若遇速率限制，请增加控制标签页中的 **提示间隔**。
2. **并发运行：** 建议从 1 个并发提示词开始，根据账号情况逐步增加。
3. **提示词编写：** 尽量具体。详细提示词带来更好效果。用空行分隔多个提示词。
4. **文件组织：** 下载内容会自动按项目分类到文件夹。

## 🔧 故障排除

| 问题 | 解决方案 |
| :--- | :--- |
| **扩展程序未激活** | 确保位于 [meta.ai](https://meta.ai) 或 [meta.ai/media](https://www.meta.ai/media)。如需请刷新页面。 |

| **需要登录** | 请确保已登录您的 Meta.ai 账户。 |
